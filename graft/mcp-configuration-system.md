## Summary

The MCP server configuration stack: jcode-mcp-config.py generates the loop's MCP config from .mcp.json, jcode-mcp-manifest.json declares the expected server set, and jcode-mcp-probe.py deterministically validates servers/readchecks/destructive tools against the manifest. Secrets are kept in the server spec's env block, never in argv (where ps could expose them), and the Keychain fallback fires only on macOS where the security binary exists — never inside the container. A config/manifest divergence is a boot crash-loop, so a sync test pins the three-way agreement (config vs manifest vs auto-loop preflight) and the OPREQ-A invariant that airtable/linear are absent from the loop config.
