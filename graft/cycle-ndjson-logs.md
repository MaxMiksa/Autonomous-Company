## Summary

The durable event-stream format (logs/cycle-ndjson) with type fields tokens/tool_start/tool_done that the cost/risk audits parse. Tool calls are reassembled from tool_start plus streamed tool_input deltas. Idempotency across these consumers is handled by deduping on filename plus size and mtime — not name alone, because the cycle counter restarts on container restart and would otherwise silently skip rewritten files.
