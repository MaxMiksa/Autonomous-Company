## Summary

Generates jcode's MCP server config from a project-local .mcp.json (wrapping HTTP/SSE servers in the mcp-remote stdio bridge, applying hard-coded overrides, refusing configs missing REQUIRED servers) and deterministically probes each server at boot via direct JSON-RPC 2.0 over stdio. The probe enforces five fail-closed gates including exact server-set match, live destructive-tool census matching the manifest, and a mandatory read-only tools/call per server — because tools/list alone proved insufficient (a server passed boot for days while never being called).
