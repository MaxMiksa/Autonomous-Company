    Settings — Runtime Config

    runtime.env

    Knobs written to logs/runtime.env (a persistent volume) and sourced on container start. Changes take effect after a redeploy/restart. runtime.env overrides the container env, which comes from both the Coolify UI and the image's own ENV defaults — so a key set in more than one place takes the value here and the other layer goes on showing one that does nothing. The entrypoint names any such key in the deploy log. This panel can only write the knobs below, never a credential. Ownership rules: docs/devops/env-ownership.md.
